# CaCO3 服务器官网设计文档

日期：2026-09-30
状态：已经用户逐节确认（结构 / 视觉 / 细节三节均已通过）

## 1. 项目概述

为 Minecraft Java 版 1.21.x 服务器 **CaCO3** 搭建纯前端官网，追求极致加载速度与简洁优雅的视觉体验。

- 主页（`/`）：满屏沉浸式 Hero、特性介绍、截图画廊、测试时间线
- 加入页（`/join`）：加入步骤指引、QQ 群二维码、复制群号
- 无后端、无数据库；构建产物为纯静态文件

### 已确认的关键决策

| 决策点 | 结论 |
|---|---|
| 默认主题 | 跟随系统 `prefers-color-scheme`，支持手动切换 |
| 视觉风格 | 现代沉浸风（大图 + 毛玻璃 + 精致排版） |
| 时间线位置 | 主页尾部章节「服务器历程」 |
| 首页方案 | 方案一：满屏大图 + 滚动分区 |
| 技术栈 | Vite + Vue 3（`<script setup>`）+ Tailwind CSS + Vue Router + TypeScript |

## 2. 技术架构与组件划分

```
web/
├── index.html
├── package.json
├── vite.config.ts
└── src/
    ├── main.ts
    ├── App.vue             # 导航栏 + 路由出口 + 页脚
    ├── router/index.ts     # / 主页、/join 加入页
    ├── content.ts          # 全站文案与数据（介绍、特性、时间线、QQ信息）
    ├── composables/
    │   └── useTheme.ts     # 主题状态：localStorage + 系统偏好 + 循环切换
    ├── components/
    │   ├── NavBar.vue
    │   ├── SiteFooter.vue
    │   ├── HeroSection.vue
    │   ├── FeatureGrid.vue
    │   ├── GallerySection.vue
    │   ├── LightboxModal.vue
    │   └── TimelineSection.vue
    ├── views/
    │   ├── HomeView.vue    # 组装四个 section
    │   └── JoinView.vue
    └── assets/images/      # 由根目录 images/ 迁入
```

- 内容与展示分离：所有文案/数据集中在 `src/content.ts`，组件只负责渲染，改文案不改组件。
- 每个组件单一职责，主页像搭积木一样组装 section。

## 3. 视觉规范

### 主题

- 切换实现：`<html>` 上加/去 `dark` 类，Tailwind `dark:` 变体生效。
- 优先级：localStorage 手动选择 > 系统偏好。
- 切换按钮：深 → 浅 → 自动 三态循环，图标显示当前态（用项目现有 `sun.png`/`moon.png` 或内联 SVG，实施时选清晰者）。

### 色彩

| 模式 | 背景 | 正文 | 点缀色 |
|---|---|---|---|
| 深色 | 夜空深蓝黑（约 `#0a0f1a`） | 舒适中灰白 | 暖橙（呼应截图灯笼暖光） |
| 浅色 | 暖白 | 深灰（非纯黑） | 深一档的橙棕 |

### 排版与留白

- 无衬线字体，标题加粗、柔和字间距；正文行高约 1.7。
- section 上下留白 `py-24` 起步，卡片间距 `gap-6~8`，保证呼吸感。

### 图片素材使用

- 深色模式用 `01~05.png`、`join.jpg`；浅色模式用对应 `*_light.png`、`join_light.jpg`。
- 所有 `<img>` 必须带描述性 `alt`。
- 画廊图 `rounded-2xl` 圆角。

## 4. 交互细节

| 位置 | 行为 |
|---|---|
| Hero | 大图背景 + 渐变遮罩保证可读；按钮「加入我们」（实心，跳 /join）、「了解更多」（幽灵，平滑滚动到特性区） |
| 导航栏 | 顶部透明，滚动后变毛玻璃 `backdrop-blur`；移动端汉堡菜单 |
| 特性卡片 | 毛玻璃 + 图标 + 标题 + 一句话说明；hover 边框微亮 |
| 画廊 | 手机 1 列、`sm` 2 列、`lg` 3 列；hover 轻微上浮放大；点击打开 Lightbox |
| Lightbox | 打开锁滚动；ESC / 点击背景 / 关闭按钮关闭；Tab 焦点圈定在弹层内 |
| 时间线 | 左竖线 + 圆点；进行中的「十二测」高亮；展示 12 轮 + 补测 |
| 加入页 | 大数字 1/2/3 步骤；QQ 二维码卡片；「复制群号」按钮成功后显示提示 |
| 响应式 | 手机单列 + 汉堡菜单；`md:`/`lg:` 渐进增强 |

## 5. 边界情况

- 图片加载失败：显示占位底色，`alt` 文字兜底。
- 复制群号：优先 Clipboard API，失败降级为选中文字手动复制，均给出用户提示。
- 主题切换：所有素材成对切换，避免深色二维码出现在浅色页面的割裂感。

## 6. 验证方式

1. `npm run build` 通过（含 TypeScript 类型检查）。
2. Playwright 本地检查：两页加载、主题切换、画廊放大/关闭、复制群号、窄屏布局、键盘可访问、控制台无报错。
